# js-file-scan-apis-token-

This script helps you download public JavaScript files and automatically scan them for sensitive tokens such as:

- API Keys
- Access Tokens
- Secrets
- Bearer Tokens

---

## 🔧 Usage

1. Clone the repository:

```bash
git clone https://github.com/your-username/bitdefender-js-secret-scanner.git
cd bitdefender-js-secret-scanner
Add your JavaScript URLs to js.txt
chmod +x secret_scanner.sh
./secret_scanner.sh
Results will appear in the terminal. Downloaded JS files are saved in the js_dump/ folder.
